# Домашнее задание 10.1 - 11.2
Программа разработана на Python для сортировки банковских операций
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/home_prj_2.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание работы функций
1. В модуле *products.py* прописаны классы Product и Category, соответственно с помощью которых можно добавлять продукты и категорировать их
## Использование программы
1. В модуле *main.py* прописана программа по запуску программы по применению классов из *products.py*, просто нажмите кнопку *Run* и проверьте код
```
print(func(args))
```


### Тестирование работы функций
Произведено тестирование работы функций, все тесты находятся в папке *tests*, отчет о покрытии тестами можно посмотреть в папке *htmlcov*, а также вызвав следующую команду:
```
pytest --cov
```
