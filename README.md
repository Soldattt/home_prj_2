# Домашнее задание 10.1 - 11.2
Программа разработана на Python для сортировки банковских операций
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/home_prj_2.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание работы функций
1. В модуле *products.py* прописаны классы:
* BaseProduct - базовый абстрактный класс с функциональностями для всех классов продуктов;
* Product - класс для описания продукта, дочерний класс от BaseProduct, имеет приватный атрибут цены, в функциональности имеет метод изменения цены (если цена больше нуля), магический метод вычисления стоимости продуктов на складе и магический метод вывода описания продукта в виде строки;
* Category - класс для категорирования продуктов класса Product или дочерних классов, список продуктов в каждой создаваемой категории является приватным атрибутом, имеет в функционале метод добавления новых продуктов в категорию(если эти продукты являются классом Product или дочерними классами), магический метод описания категории с указанием количества товаров;
* Iterator - класс для перебора продуктов в категориях с выводом описания каждого продукта.
2. В модулях *lawngrass.py* и *smartphone.py* прописаны классы:
* LawnGrass - дочерний класс от Products, описывающий траву и имеющий весь функционал класса родителя;
* Smartphone - дочерний класс от Products, описывающий смартфоны и имеющий весь функционал класса родителя.
3. В модуле *print_mixin* прописан класс PrintMixin который выводит в консоль описание продукта с указанием его класса
## Использование программы
1. В модуле *main.py* прописана программа по запуску программы по применению классов из *products.py*, просто нажмите кнопку *Run* и проверьте код
```
print(func(args))
```
